# 開発ビルドの作り方（EAS Build / Android）

開発ビルド = 「自分専用のExpo Go」。MediaPipeのような追加部品を焼き込んだ専用アプリを1回作ってスマホに入れる。以後の画面・ロジック変更は今まで通り `npx expo start` から即反映され、作り直しはネイティブ部品を変えた時だけ。

所要時間: 初回はアカウント作成込みで30分程度（ビルドの順番待ち・実行に10〜20分ほどかかることがある）。すべて無料枠の範囲。

## 手順（PCで実行）

プロジェクトの場所で、黒い画面（ターミナル）に上から順に打つ。

### 1. 最新コードを持ってくる
```
cd C:\dev\cord-rogue
git pull
```

### 2. Expoアカウントを作る（初回だけ）
ブラウザで https://expo.dev を開き、Sign up から無料アカウントを作成する（メールアドレスとパスワードだけ）。

### 3. EASの道具を入れる（初回だけ）
```
npm install --global eas-cli
```

### 4. ログインする
```
eas login
```
作ったアカウントのメールアドレスとパスワードを聞かれるので入力する。

### 5. ビルドする
```
eas build --profile development --platform android
```
途中で聞かれること（全部デフォルトの「Yes」でよい）:
- プロジェクトをExpoに紐付けるか → Yes
- Androidの署名鍵（Keystore）を作るか → 「Generate new keystore」でYes

ビルドはExpoのサーバで実行される。終わると画面にリンクとQRコードが出る。

### 6. スマホに入れる
スマホでQRコードを読むか、リンクを開いてアプリ（APK）をインストールする。Androidが「提供元不明のアプリ」を警告したら、このインストールだけ許可する。

インストールされるのは Expo Go ではなく **cord-rogue という名前の専用アプリ**。

### 7. 開発サーバにつなぐ
PCで:
```
npx expo start --dev-client
```
スマホで cord-rogue アプリを開くと、PCのサーバに接続して最新コードが動く。PCとスマホは同じWi-Fiにいること。

## 2回目以降
- 画面や計算ロジックだけの変更: 手順7だけでよい（ビルドし直し不要）
- ネイティブ部品（顔検出など）を足した／変えた時だけ: 手順5〜6をもう一度

## つまずきやすい点
- 無料枠は月のビルド回数に上限がある。開発ビルドは部品を変えた時だけ作るので、通常は十分足りる
- ビルドの順番待ちが長い時は無料枠の混雑。時間を置いて再実行すればよい（コードの問題ではない）
- `eas build` の途中で app.json にプロジェクトIDが自動で書き込まれる。終わったら `git add -A && git commit -m "eas init" && git push` で置き場にも反映しておくと安全
