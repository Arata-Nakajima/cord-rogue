# GitHub経由の連携手順（Muse ⇔ Antigravity）

## 役割分担
- **Muse（このリポジトリのcore担当）**: 設計、核ロジック（MV計算・マッチング・ペナルティ等）、テスト、レビュー。サーバー側の作業環境でコードを書き、GitHubへ push する
- **Antigravity（ユーザーのPC担当）**: Expoアプリの土台、画面実装、実機（Android + Expo Go）での動作確認。作業前に必ず pull し、作業後に push する
- **ユーザー**: Antigravityへの指示出し（定型文でよい）と、実機で触った感想の共有

## 置き場所の約束
- 核ロジックは `src/core/`（TypeScript化したものが正。Muse側の `src/*.js` は原型）
- 画面は Expo プロジェクト側（`app/` など、テンプレートの構成に従う）
- 設計判断は `docs/` と設計メモが正。迷ったらコードより先にドキュメントを確認する

## 運用ルール
1. 作業を始める前に `git pull` して最新にする
2. 作業は小さく区切り、終わるたびに `git push` する（大きな変更を溜めない）
3. コミットメッセージは「何をしたか」を1行で書く（例: `feat: add MV calculation`）
4. 相手の担当ファイルを大きく書き換える前に、コミットメッセージかPRで一言残す
5. 秘密情報（トークン、パスワード、個人情報）は絶対にコミットしない

## 典型的な1往復
1. Muse が核ロジックや設計を更新して push
2. ユーザーが Antigravity に「最新を pull して、docs/WORKFLOW.md と設計メモに従って画面に組み込んで」と一言
3. Antigravity が実装して push、ユーザーが実機確認の結果を Muse に共有
4. Muse が差分（diff）を読み、テストとレビュー結果を返す
